# 赛题二·硬件选型与采购清单（采购版 v5）

> 适用队伍：3 名大二学生、嵌入式和机器视觉经验有限、20 天左右完成首个可运行版本。
> 采购原则：先保证小车能稳定循迹，再增加识别功能；避免买很多模块后再临时拼装。

## 一、最终推荐架构

```text
前视 CSI 摄像头 ──> 树莓派 4B 2GB：交通指示牌识别、颜色识别、显示任务信息
8 路红外循迹阵列 ──> STM32F103C8T6：实时循迹、PWM、电机、超声波、状态机
树莓派 UART <──> STM32F103C8T6：传递 sign / color / valid 等结果
```

### 主控怎么选

- **直接使用现有 STM32F103C8T6 + ST-Link 作为实时控制板。** 不再购买 Pico。
- **视觉板建议树莓派 4B 2GB。** Zero 2W 只有在已经有现货、预算非常紧时才用；第一次做视觉不建议把它作为主方案。

## 三、建议一起买的备用件

| 器件 | 数量 | 原因 |
|---|---:|---|
| TB6612FNG | 1 | 电机反接或短路时快速替换 |
| 8 路循迹阵列 | 1 | 传感器损坏或需要不同安装高度 |
| TT 电机 | 2 | 左右电机性能不一致时替换 |
| 车轮 | 2 | 抓地力和同心度会直接影响循迹 |
| HC-SR04 | 1 | 避障模块备用 |
| TF 卡 32GB | 1 | 树莓派系统损坏时快速恢复 |
| 470µF 电容 | 2 | 抑制电机启动造成的电压跌落 |

## 四、暂缓或不要购买

- 编码器、陀螺仪、激光雷达、舵机：首版不需要，增加调试面。
- K210、Pico 等其他主控：你们已有 STM32，不再购买。
- L298N：压降大、发热明显，优先 TB6612FNG。
- USB 摄像头：线缆和驱动增加不稳定因素，优先 CSI。
- 自定义 PCB、3D 打印底盘：20 天内不值得承担返工风险。
- 多套红外避障模块：规则允许超声波，先用一个 HC-SR04 完成避障。

## 五、供电和接线硬规则

```text
2S 电池
  ├─ 保险丝 ─> 6V/5A 降压 ─> TB6612 VM（电机）
  ├─ 5V/5A 降压 ─> 树莓派 5V
  └─ 5V/2A 降压 ─> STM32/传感器

电池负极、树莓派、STM32、TB6612 共地；电机大电流回路不要经过树莓派供电线。
```

1. 接板子前先测三路降压输出：树莓派 5.0V±0.2V、STM32 5.0V±0.2V、电机 5.5～6.0V。
2. 树莓派、STM32 和电机分别取电，只共地。STM32 开发板若是常见 Blue Pill，5V 接 5V/VIN 输入脚，禁止把 5V 接到 3V3 脚。
3. 电机驱动的 VM 接电机降压后的 5.5～6.0V，不能把 2S 电池满电电压直接接给普通 3～6V TT 电机；逻辑电源按模块标注接 3.3V/5V。
4. 树莓派 UART 与 STM32 都是 3.3V 电平，可直接连接 TX/RX/GND；禁止把 5V 信号直接接到树莓派 GPIO。HC-SR04 的 Echo 可能为 5V，接 STM32 前加分压或电平转换。
5. STM32 先单独烧录 PWM 和串口程序；摄像头、颜色传感器和 OLED 都先单独验收，再装车。

## 六、STM32 与树莓派供电兼容说明

STM32F103C8T6 和树莓派 GPIO/UART 都使用 3.3V 逻辑，UART 的 TX、RX、GND 可以直接互连。供电不能把两块板的电源脚随意并接：树莓派由 5V/5A 降压供电，STM32 开发板由 5V/2A 降压接 5V/VIN 输入；只有共地，且两边都禁止向对方的 3V3 脚供电。若你们的 STM32 板不是常见 Blue Pill，先看板上 5V/VIN/3V3 标识。

## 七、采购验收顺序

1. 电池、充电器、三路降压模块和万用表：先确认电压安全。
2. 先接电机降压和 TB6612，确认电机端 5.5～6.0V，再接现有 STM32 完成正反转和 PWM。
3. 循迹阵列：手动移动黑线，确认 8 路输出变化。
4. 树莓派、CSI 摄像头和 TF 卡：能启动、能出图、能保存照片。
5. OLED、TCS34725、HC-SR04：分别跑最小示例。
6. 最后才装车和接串口；不要一到货就把所有模块同时接上。

## 八、下单前的尺寸检查

- 底盘投影、最高点和摄像头支架一起测量，确保满足赛题尺寸限制。
- 摄像头不要高出车体太多，支架要有防撞保护。
- 颜色传感器要能靠近目标色块，但不能碰地；预留上下调节孔。
- 电池、树莓派和降压模块尽量放在底盘中部，降低重心。
