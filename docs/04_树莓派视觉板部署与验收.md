# 树莓派视觉板部署与验收手册

本文对应当前项目，目标是让树莓派 4B 完成 CSI 摄像头取图、ST7789 SPI 液晶显示、视觉识别和 UART 上报。请按顺序执行，每完成一节先验收再进入下一节。

## 1. 当前方案

| 部件 | 当前方案 |
|---|---|
| 主控 | Raspberry Pi 4B |
| 摄像头 | CSI 摄像头，建议 Camera Module 3 Standard 或明确支持 Pi 4B 的 IMX219 |
| 显示 | 2 英寸 ST7789V2 SPI 液晶屏，240×320，3.3V，4 线 SPI |
| 颜色传感器 | TCS34725，当前用于校准和备选测色 |
| 控制板 | STM32F103C8T6 |
| UART | 115200，8-N-1，3.3V |
| 项目目录 | /home/pi/projects/racecar |
| Python 环境 | /home/pi/projects/racecar/.venv |

图片资料确认屏幕是 ST7789V2、240×320、3.3V、4 线 SPI、8 针 2.54 mm 排针。代码使用 LCD_WIDTH=240、LCD_HEIGHT=320 和 LCD_ROTATE=1 横屏显示。屏幕排针定义仍以 PCB 丝印为准。

## 2. 首次登录和系统更新

在树莓派首次启动界面设置用户名、密码、网络、时区和 SSH。查看 IP：

    hostname -I

Windows PowerShell 登录：

    ssh pi@192.168.1.108

将用户名和 IP 换成实际值。登录后更新系统：

    sudo apt update
    sudo apt full-upgrade -y
    sudo apt autoremove -y
    sudo reboot

重启后确认：

    cat /etc/os-release
    cat /proc/device-tree/model
    uname -m
    hostname -I

## 3. 软件源速度慢时

查看当前源：

    grep -R "^deb\|^URIs:" /etc/apt/sources.list /etc/apt/sources.list.d 2>/dev/null

常见配置文件：

    /etc/apt/sources.list.d/debian.sources
    /etc/apt/sources.list.d/raspi.sources

修改前备份：

    sudo mkdir -p /etc/apt/sources.backup
    sudo cp -a /etc/apt/sources.list.d/debian.sources /etc/apt/sources.backup/
    sudo cp -a /etc/apt/sources.list.d/raspi.sources /etc/apt/sources.backup/

可以把官方源换成可靠的国内镜像，也可以换用网线或手机热点。不要混用 Trixie 和 Bookworm 源。修改后执行：

    sudo apt clean
    sudo apt update

## 4. 开启接口

运行：

    sudo raspi-config

开启 SPI：

    Interface Options -> SPI -> Yes

开启 I2C：

    Interface Options -> I2C -> Yes

开启 UART 时选择：

    Interface Options -> Serial Port
    login shell over serial: No
    serial port hardware: Yes

重启并检查：

    sudo reboot
    ls -l /dev/spidev0.0
    ls -l /dev/serial0

安装 I2C 检查工具：

    sudo apt install -y i2c-tools
    sudo i2cdetect -y 1

TCS34725 接好时通常看到地址 29。ST7789 使用 SPI，不会出现在 I2C 表中。

从 Git 仓库复制：

    mkdir -p ~/projects

## 6. 安装系统依赖

    sudo apt install -y \
        python3 python3-pip python3-venv python3-dev \
        python3-opencv python3-numpy python3-picamera2 \
        python3-pil python3-serial python3-smbus \
        python3-spidev python3-rpi.gpio rpicam-apps i2c-tools

不要使用 sudo pip 安装 opencv-python 或 picamera2。相机和 OpenCV 使用系统包更容易保持兼容。

创建虚拟环境：

    cd ~/projects/racecar
    python3 -m venv --system-site-packages .venv
    source .venv/bin/activate
    python -m pip install --upgrade pip
    python -m pip install -r vision/requirements.txt

每次新开终端都执行：

    cd ~/projects/racecar
    source .venv/bin/activate

检查路径：

    which python

结果应类似 /home/pi/projects/racecar/.venv/bin/python。

检查依赖：

## 7. 验收 CSI 摄像头

摄像头必须断电安装。确认排线两端插紧、锁扣压好，并接入树莓派 CAMERA 接口。

    rpicam-hello --list-cameras

如果没有这个命令：

    libcamera-hello --list-cameras

保存测试图片：

    rpicam-still -o ~/camera_test.jpg
    ls -lh ~/camera_test.jpg

检查 Picamera2：

    python - <<'PY'
    from picamera2 import Picamera2
    camera = Picamera2()
    print(camera.camera_properties)
    camera.close()
    PY

没有摄像头时检查：

    dmesg | grep -i -E "imx|camera|unicam|bcm2835-unicam|libcamera"

不要只筛选 csi，因为 SCSI 存储日志也会被误匹配。

## 8. ST7789 接线和配置

默认接线：

| ST7789V2 | BCM GPIO | 物理引脚 |
|---|---:|---:|
| VCC | 3V3 | 17 |
| GND | GND | 6 |
| SCLK/SCL | GPIO11 | 23 |
| SDA/MOSI | GPIO10 | 19 |
| CS | GPIO8 | 24 |
| DC/A0 | GPIO24 | 18 |
| RES/RST | GPIO25 | 22 |
| BLK/LED | GPIO18 | 12 |

vision/config.py 的默认配置：

    LCD_SPI_PORT = 0
    LCD_SPI_DEVICE = 0
    LCD_SPI_SPEED_HZ = 32_000_000
    LCD_WIDTH = 240
    LCD_HEIGHT = 320
    LCD_ROTATE = 1
    LCD_DC_PIN = 24
    LCD_RESET_PIN = 25
    LCD_BACKLIGHT_PIN = 18

如果 BLK 已接 3.3V：

    LCD_BACKLIGHT_PIN = None

运行独立测试：

    cd ~/projects/racecar/vision
    source ../.venv/bin/activate
    python tools/test_lcd.py

屏幕应显示测试标题、颜色顺序和左转状态。

只有背光时，依次检查 VCC、GND、SCLK、MOSI、CS、DC、RST、BLK、分辨率和旋转。确认 /dev/spidev0.0 存在后，可以把 LCD_SPI_SPEED_HZ 从 32000000 降到 16000000。方向错误时依次尝试 LCD_ROTATE 为 0、1、2、3。

## 9. 运行视觉主程序

先使用无 UART 模式：

    cd ~/projects/racecar
    source .venv/bin/activate
    python vision/main.py --no-uart

检查摄像头取图、ST7789 显示、指示牌连续确认和颜色顺序锁存。按 Ctrl+C 停止。

保存调试图：

    python vision/main.py --no-uart --debug

调试图片位于 media/debug。正式运行时关闭 --debug。

## 10. UART 接线和联调

| 树莓派 | STM32 |
|---|---|
| GPIO14 TXD | RX |
| GPIO15 RXD | TX |
| GND | GND |

TX 和 RX 交叉连接，两边使用 3.3V 逻辑。

协议自检：

    cd ~/projects/racecar
    source .venv/bin/activate
    python vision/protocol.py

启动串口发送：

    python vision/main.py

帧格式：

    AA 55 sign color_valid color_seq quality checksum

STM32 需要检查帧头、长度、校验和、低置信度、串口超时和指示牌锁存时间。

## 11. 测试和真实样本

运行回归测试：

    cd ~/projects/racecar
    source .venv/bin/activate
    python -m unittest discover -s vision/tests -v
    python -m compileall -q vision

当前测试覆盖指示牌确认和失效、颜色锁存和重复颜色、协议校验、UART 短写和重连。

摄像头固定到车上后采集真实样本：

    cd ~/projects/racecar/vision
    source ../.venv/bin/activate
    python tools/capture.py --label left --n 30
    python tools/capture.py --label right --n 30
    python tools/capture.py --label none --n 30
    python tools/tune_sign.py media/capture/left
    python tools/tune_sign.py media/capture/right
    python tools/replay.py media/capture/left --kind sign
    python tools/replay.py media/capture/right --kind sign
    python tools/replay.py media/capture/none --kind sign

样本应覆盖左右标志、无标志、不同距离、不同光照、反光、运动模糊和重复颜色。

当前指示牌算法仍需按照蓝底白色箭头识别方向，不能只根据牌面在画面中的左右位置判断。颜色顺序必须按车辆行驶方向确认，重复颜色已经允许。

## 12. 常见错误

摄像头无输出时，断电重插排线，检查 CAMERA 接口、摄像头型号和驱动。日志中只出现 SCSI 时，说明筛选到了存储日志。

出现 No module named luma：

    source ~/projects/racecar/.venv/bin/activate
    python -m pip install luma.lcd

出现 No module named RPi：

    sudo apt install -y python3-rpi.gpio

出现 No module named picamera2：

    sudo apt install -y python3-picamera2

如果虚拟环境读不到系统包：

    cd ~/projects/racecar
    rm -rf .venv
    python3 -m venv --system-site-packages .venv
